# Math Souls

## A cool math game

Throughout my childhood I spent countless hours on various websites such as **coolmathgames, kizi, and newgrounds** playing games of all genres. In my early schooling, a select few of my teachers chose to incorperate online games to encourage learning. In particular, instructors in charge of developing our technology literacy introduced us to many math games, which aimed to train our **mental math**. Even now, I find myself searching for these games to alleviate some boredom, only to find that the games have been taken down. Thus, to alleviate my boredom and bring back some nostelgia I have decided my term project to be a simple math-based rpg. Though this game might seem to be targeted to children, I hope that anyone who finds comfort in challenging their brain enjoys their playthrough!\
\
This is a game inspired by the web game Swords and Souls, as well as the many other web math games I played throughout my childhood.  This game is meant to be a simple take on the **rpg** *role-playing game* genre, combined with **turn-based combat**. The main feature of this game are the **math/logic** problems the user has to complete in order to progress. To defeat enemies, the user must answer the problems within a certain time interval.
To keep things as **simple** as possible, this game will have:
- 5 stages
- 3 rounds/stage
- 10 unique enemies + 5 'bosses'
- A leveling system
